## 🧩 Práctica 5: Fondo, sprites y animación

**Descripcion** 
Este proyecto implementa un videojuego 2D basico en Python utilizando la libreria Pygame, simulando mecanicas de fisica como la gravedad en el salto del personaje y un efecto de desplazamiento lateral infinito (scroll) del fondo. Para probarlo, es necesario instalar la libreria (pip install pygame) y ejecutar el script juego.py, asegurandose estrictamente de que las imagenes fondo.png y personaje.png se encuentren en la misma carpeta que el archivo de codigo, ya que el sistema incluye una validación de seguridad que cerrará el programa automáticamente si no detecta estos recursos graficos al iniciar.
